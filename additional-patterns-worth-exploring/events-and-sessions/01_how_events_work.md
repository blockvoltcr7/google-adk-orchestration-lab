# Lesson 1: How Events Work in Google ADK

## 1. What is an Event?

In the **Google Agent Development Kit (ADK)** (`google.adk`), an **`Event`** is a Pydantic-based data structure (`google.adk.events.Event`) representing a single atomic occurrence during an agent's execution lifecycle.

An `Event` contains:
- **Identification & Metadata:** `id`, `invocation_id`, `timestamp`, `author` (`"user"` or agent name), and `node_info` (path in the workflow graph).
- **Payload (`content`):** `types.Content` carrying user prompts, LLM response text, or function call/response parts.
- **Actions (`actions`):** An `EventActions` object containing `state_delta` (mutations for `session.state`), routing instructions, or agent state metadata.

```text
+-------------------------------------------------------------+
|                      GOOGLE ADK EVENT                       |
+-------------------------------------------------------------+
| id            : "evt_987654321"                             |
| invocation_id : "inv_12345"                                 |
| author        : "intake_agent"                              |
| timestamp     : 1785640000.0                                |
| node_info     : NodeInfo(path="root/intake_agent")          |
+-------------------------------------------------------------+
| content       : Content(parts=[Part(text="Valid intake")])  |
| actions       : EventActions(state_delta={"valid": True})   |
+-------------------------------------------------------------+
```

---

## 2. Event Types & Taxonomy

ADK organizes events based on their author and actions payload:

| Event Category | Author | Description & ADK Attributes |
| :--- | :--- | :--- |
| **User Message Event** | `"user"` | User prompt content passed into `runner.run(user_message=...)`. |
| **Model Output Event** | Agent Name | Response generated by `LlmAgent` containing text or thinking parts. |
| **Function Call Event** | Agent Name | Request containing `get_function_calls()` to execute tools. |
| **Function Response Event** | `"user"` / Tool | Return data containing `get_function_responses()` from executed tools. |
| **State Delta Event** | Agent / System | `event.actions.state_delta` dict carrying state mutations to `session.state`. |
| **Node / Output Event** | Agent Name | Event carrying workflow node results (`event.output`). |

---

## 3. The ADK Event Loop (Turn Lifecycle)

When `runner.run()` is called, the ADK **Runner** manages the execution loop:

```text
User Input -> [1. Runner fetches Session Events from SessionService]
                   |
                   v
              [2. Runner builds LlmRequest Prompt Context]
                   |
                   v
              [3. LlmAgent & Gemini Model Execution]
                   |
            +------+------+
            | Yields      |
            v             v
      Model Output    Function Call
            |             |
            v             v
     [4. Runner calls session_service.append_event()]
                   |
                   v
     [5. Events persisted & session.state updated]
                   |
                   v
     [6. Events yielded asynchronously to caller]
```

## 4. Code Example: Inspecting Google ADK Events in Python

```python
import asyncio
from google.adk.agents import LlmAgent
from google.adk.events import Event
from google.adk.models import Gemini
from google.adk.plugins import BasePlugin
from google.adk.runners import Runner
from google.adk.sessions import InMemorySessionService

# Create a custom ADK Plugin to observe every event produced by the runner
class EventInspectorPlugin(BasePlugin):
    def __init__(self):
        super().__init__(name="event_inspector")

    async def on_event_callback(self, *, invocation_context, event: Event):
        print(f"\n[EVENT INSPECTOR PLUGIN]")
        print(f"  Event ID      : {event.id}")
        print(f"  Author        : {event.author}")
        print(f"  Node Path     : {event.node_info.path}")
        if event.actions.state_delta:
            print(f"  State Delta   : {event.actions.state_delta}")
        if event.is_final_response():
            print(f"  Final Response: True")
        return None

# Setup ADK components
model = Gemini(model="gemini-3.6-flash")

agent = LlmAgent(
    name="calculator_agent",
    model=model,
    instruction="Calculate mathematical requests directly.",
)

session_service = InMemorySessionService()
session_service.create_session(session_id="calc_session", app_name="calc_app")

runner = Runner(
    agent=agent,
    session_service=session_service,
    plugins=[EventInspectorPlugin()],
)

async def main():
    events = runner.run(
        session_id="calc_session",
        user_message="What is 42 multiplied by 7?",
    )
    async for event in events:
        pass

if __name__ == "__main__":
    asyncio.run(main())
```
