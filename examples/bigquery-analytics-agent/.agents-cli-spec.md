# BigQuery Retail Analytics Agent Specification

## Goal

Build a local Google ADK agent that answers natural-language questions about a
small, synthetic retail dataset in BigQuery and proves its behavior with ADK
evaluations.

## Scope

- One ADK `Agent` using Google's supported `BigQueryToolset`.
- One Terraform-managed BigQuery dataset in `your-gcp-project-id`, location `US`.
- One materialized, denormalized 2024 retail table seeded from Google's
  `bigquery-public-data.thelook_ecommerce` public dataset.
- Read-only query execution, a 100 MiB per-query billing cap, and at most 50
  returned rows.
- Local runtime and evaluation only. No remote ADK deployment in this phase.
- A cleanup script that previews dataset destruction by default; it is not
  executed during initial validation.

## Out of scope

- Cloud SQL, AlloyDB, writes, DML, BigQuery ML model creation, production IAM,
  CI/CD, and a hosted UI.

## Success criteria

1. Terraform creates the dataset and a seed operation creates the retail table.
2. Verification proves the table contains only 2024 data and expected rows.
3. The local agent uses `execute_sql` for data answers and refuses writes.
4. Unit/integration tests and Agents CLI evals run successfully.
5. Cleanup can be safely previewed without deleting the active dataset.
