# ADK Pattern Visuals

Each concept has one folder containing:

```text
visuals/<concept-name>/
├── README.md
└── <concept-name>.png
```

The folder README explains the purpose, topology, ADK expression, data movement,
tradeoffs, failure modes, and neighboring patterns. The PNG is the corresponding
teaching diagram.

See the [root catalog](../README.md) for the complete learning order and decision
map.
